# NoStall EnvLite

**Lightweight environment management tool for NoStall ecosystem**

NoStall EnvLite is a minimal, fast, and reliable environment variable management tool designed to work seamlessly with the NoStall AI platform.

## Features

- 🚀 **Lightweight**: Minimal dependencies, fast startup
- 🔒 **Secure**: Encrypted environment variable storage
- 🔄 **Sync**: Easy synchronization across environments
- 🛠️ **CLI**: Simple command-line interface
- 📦 **PyPI Ready**: Installable via pip

## Installation

```bash
pip install nostall-envlite
```

## Quick Start

```bash
# Initialize environment
envlite init

# Set environment variable
envlite set API_KEY=your_key_here

# Load environment
envlite load

# Sync to remote
envlite sync
```
